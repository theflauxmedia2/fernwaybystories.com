# Fernway by Stories

Marketing website for **Fernway by Stories** — open-air lounge & kitchen on Bengaluru Mysore Highway, Mayaganahalli.

Live site: [https://fernwaybystories.com](https://fernwaybystories.com)

---

## Deploy to Hostinger (or any static host)

This is a **static website**. There is no server-side code — only HTML, CSS, JS, and images.

### One-time setup on Hostinger

1. **Use static hosting only**  
   In hPanel → **Websites** → `fernwaybystories.com`:
   - Disable or remove any **Node.js Web App** or Git deployment for this domain.
   - The site must be served from **`public_html`**, not a Node process.

2. **DNS**  
   Point `fernwaybystories.com` to Hostinger. `www` redirects to non-www via `.htaccess` (included in the build).

---

### Every deploy

```bash
npm install          # first time only, or after pulling changes
npm run build        # creates deploy-ready files in out/
```

Then either:

**Option A — zip locally (optional convenience):**

```bash
npm run zip          # creates fernwaybystories-static.zip from out/
```

**Option B — zip manually:**

Compress everything **inside** the `out/` folder (not the `out` folder itself).

Upload to Hostinger:

1. hPanel → **File Manager** → **`public_html`**
2. **Delete old site files** (especially any `_next` or `next-assets` folders)
3. Upload your zip and **extract inside `public_html`**
4. Purge cache (hPanel → Cache Manager) and hard-refresh your browser

After extract, `public_html` should look like:

```
public_html/
├── index.html
├── .htaccess
├── next-assets/
│   └── static/chunks/*.css
├── about/index.html
├── menu/index.html
├── gallery/
├── contact/
├── events/
└── … (images, video, etc.)
```

**Important:** Extract so `index.html` sits directly in `public_html`, not in `public_html/out/`.

---

### Deploy workflow

```
Edit code  →  npm run build  →  zip out/  →  upload to public_html  →  extract  →  purge cache
```

Optional shortcut: `npm run package:hostinger` runs build + zip in one step (same as `npm run build && npm run zip`).

## Updating site content

Most content lives in code files — no CMS.

| What to change | File |
|----------------|------|
| Phone, hours, address, booking links | `lib/site.ts` |
| Menu items | `lib/menu-data.ts` |
| Gallery images & captions | `lib/gallery-items.ts` |
| Events | `lib/events-data.ts` |
| SEO & metadata | `lib/seo.ts`, `app/*/page.tsx` |
| Images / video | `public/` |

After any change, run `npm run build` and redeploy.

### Adding new images

1. Drop raw images into `public/new_images/`
2. Run `npm run compress:images`
3. Update `lib/gallery-items.ts` if they should appear on the site
4. Run `npm run build` and deploy

## Troubleshooting

#### Site looks unstyled (plain HTML)

- Re-run `npm run build` and upload a fresh copy
- Confirm `public_html/next-assets/static/chunks/*.css` exists
- Delete leftover `_next` folders from old uploads
- Disable any Node.js app for this domain
- Purge Hostinger cache

#### Homepage broken but `/menu/` works

The root URL is still served by an old Node.js deployment. Disable it in hPanel and purge cache.

#### 404 on inner pages

Extract the zip fully. Each route folder (`about/`, `menu/`, etc.) must contain `index.html`.
